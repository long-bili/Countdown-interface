2026 春节倒计时页面
这是一个视觉精美、功能完整的 2026 春节倒计时网页，包含倒计时展示、春节科普、祝福弹窗、烟花特效等功能，适配移动端与桌面端，交互流畅且样式美观。
一、页面核心功能
精准春节倒计时：目标时间为 2026 年 2 月 17 日（农历正月初一），实时展示天、时、分、秒剩余时间，数字变化时带有炫酷飞出动画效果
春节科普卡片：12 张精美科普卡片，涵盖节日由来、习俗、美食、海外春节等内容，点击卡片可全屏查看详细信息
暖心祝福弹窗：点击 "获取春节祝福" 按钮，弹出包含 6 条新春暖心祝福的弹窗，支持点击关闭或空白处关闭
炫酷烟花特效：默认开启页面背景烟花动画，支持通过按钮开启 / 关闭烟花，同时可点击按钮跳转至专属烟花秀页面
实用辅助功能：包含当前时间实时显示、回到顶部按钮、社交账号展示、全屏卡片交互、弹窗遮罩等功能
倒计时结束处理：倒计时结束后自动恢复页面滚动与点击交互，延迟 1.5 秒后自动跳转至指定链接
二、页面特性
1. 响应式适配
适配移动端（≤480px）、平板、桌面端等不同设备尺寸
采用 clamp() 函数实现字体与间距的自适应缩放，卡片布局自动换行
移动端优化倒计时布局、卡片宽度，保证操作便捷性
2. 视觉美观度
采用春节主题配色（红、粉、紫渐变），搭配清新背景动效
丰富的 CSS 动画：页面淡入、标题滑入、卡片飞入、烟花脉动、按钮悬浮效果等
渐变文字、阴影效果、毛玻璃遮罩等现代 UI 样式，提升视觉层次感
3. 交互友好性
卡片点击全屏、弹窗关闭、回到顶部平滑滚动等流畅交互
按钮悬浮时有缩放与阴影变化，提升操作反馈感
倒计时结束后自动恢复页面交互权限，解决元素无法点击的问题
点击遮罩层空白处可关闭弹窗 / 全屏卡片，操作符合用户习惯
三、快速使用
直接将 HTML 文件保存为 .html 格式（如 2026SpringFestival.html）
用任意现代浏览器（Chrome、Edge、Safari 等）打开该文件即可运行
无需依赖第三方库，原生 HTML/CSS/JavaScript 实现，零额外配置
